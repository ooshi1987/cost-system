# ハンドオフ: 管理者PC「日次集計表」を1cデザインに合わせて実装

## 概要
サイドバーに既にある「日次集計表」ナビ項目のページ本体を、モックアップ `Costra 全体モックアップ.dc.html` の `#1c` セクションの見た目・構成に合わせる。現在のExcel(損益計算書)と同じ列構成で1日1行、**表示専用**(修正不可)。

## 画面構成
- サイドバー: 既存の1a(ダッシュボード)と共通。「日次集計表」項目をアクティブ状態(オレンジ#c84a1f背景、白文字)で表示。
- ヘッダー: 「日次集計表」見出し + 店舗名・月・「表示専用」の説明文。右側に月選択(ドロップダウン)と「CSV / PDF 出力」ボタン(オレンジ)。
- 注記: 「修正はこの画面ではできません。読み間違いや仕分けの修正は、現場の記録画面(撮影・入力)側で行ってください。」を必ず表示。
- テーブル: 横スクロール可、ヘッダー2段(グループ見出し+列見出し)は`sticky top`。
  - グループ見出し: 「売上」(緑背景#e4efe9/文字#1f8a5b) / 「仕入先別支出」(オレンジ背景#f7e6dc/文字#c84a1f)。
  - 列: 日・曜・現金・クレジット・オンライン・売上合計 / 仕入先ごとの列(食材仕入先を動的に列化、例: 豊洲水産・カクヤス・マルエツ)・消耗品・水道光熱費・その他・支出合計・差引。
  - データが無いセルは「—」。差引は正なら緑、負なら赤系(#c0392b)。
  - 最終行「◯月度合計」は黒背景(#1a1815)、白文字、`sticky bottom`。
- 行の背景は1行おきに薄い縞(#fbfaf6)。

## データソース
既存の `Transaction` モデル(storeId・日付・科目・支払方法・金額)を日付×科目で集計。仕入先は取引先名(既存フィールド)でグルーピングし、件数が多い上位N社を列化、残りは「その他」に合算。売上の内訳(現金/クレジット/オンライン)は既存の支払方法区分に対応させる。

## CSV / PDF出力
表示中の月のテーブルをそのままCSV/PDF化。既存の `/api/reports` にエクスポート用エンドポイントがあれば拡張、なければ新規追加。

## 完了条件
- サイドバーの「日次集計表」がアクティブ表示になり、モックアップと同じ列構成・色分けで表示される。
- 月を切り替えると集計が再計算される。
- CSV/PDF出力が動作する。
- この画面から値の編集ができないこと(表示専用)。
