# ハンドオフ: 日次集計表（今のExcel「損益計算書」と同じ見え方のビュー）

## 概要
現場は今後スマホで撮影・入力して記帳するが、運営が今まで見ていたのはExcel（Googleスプレッドシート）の「損益計算書」シート — 1日1行、左に売上の内訳（現金/クレジット/オンライン等）、右に仕入先ごとの支出額が並ぶ表。
移行でいきなり画面が変わると現場・管理者とも混乱するため、**管理者PCのダッシュボードに、今のExcelと同じ列構成・同じ見え方の集計表を新設**する。データの出どころは今後アプリに集約される取引記録（現場の記録から自動生成）。**表示専用**（このプロジェクトの方針どおり、修正は現場の入力画面側で行う。集計画面では数値を直接編集しない）。

## このバンドルのファイルについて（重要）
このフォルダの HTML は **HTML で作成したデザイン参照（プロトタイプ）** です。見た目と挙動の意図を示すもので、**本番にそのままコピーするコードではありません**。
本番は別リポジトリ（Next.js App Router + Prisma、ローカルフォルダ「cost system」、本番 `cost-system.app`）です。タスクは、このプロトタイプの**意図を、本番コードベースの既存パターン（Tailwind、amber系アクセント、既存コンポーネント/APIルート/Prismaスキーマ）に合わせて実装すること**です。同梱の `指示書.md` が実装の正本です。

## 忠実度
**ハイファイ（hifi）に近いレイアウト参照**。列構成・グループ分け（売上／仕入先別支出）・行の並び・合計行の位置関係は最終想定。
ただし**色・タイポは本番の既存デザインシステム（Tailwind, amber系）に合わせること**。プロトタイプは Costra ブランドトークン（オレンジ `#c84a1f` 等）で描いているが、本番はこれに揃えるか、ブランド移行時のみ差し替える。
**仕入先の列構成は仮**（プロトタイプでは「豊洲水産／カクヤス／マルエツ／消耗品／水道光熱費／その他」の6分類）。実データでは取引先が数十社に及ぶため、本番は**固定列ではなく上位N社＋その他で動的に構成**する方針（詳細は指示書のタスク2）。

## 画面
プロトタイプ（`Costra 全体モックアップ.dc.html` の管理者PCレーン、`1c 日次集計表` の画面）が対象。既存の `1a サイドバー型ダッシュボード` に新しいナビ項目として追加する形。

### レイアウト
- 左サイドバー: 既存の1a同様（店舗切替・ダッシュボード・取引履歴・**日次集計表**［新規/選択中］・原価・レシピ・月次レポート・設定）。
- ヘッダー: 画面名「日次集計表」＋サブテキスト「{店舗名}・今のExcel（損益計算書）と同じ列構成・表示専用」。右上に月選択（プルダウン、例「2026年 1月」）と「CSV / PDF 出力」ボタン。
- 注記テキスト: 「修正はこの画面ではできません。読み間違いや仕分けの修正は、現場の記録画面（撮影・入力）側で行ってください。」— 常時表示。
- テーブル本体（白カード、横スクロール可・ヘッダー行は縦スクロール時に上部固定）:
  - グループヘッダー行: 「日/曜」列の上は無地、その右に緑背景「売上」、その右にオレンジ背景「仕入先別支出」、末尾「差引」列の上は無地。
  - 列ヘッダー行: 日 / 曜 / 現金 / クレジット / オンライン / 売上合計 / {仕入先1} / {仕入先2} / … / その他 / 支出合計 / 差引。
  - 日別行: 31日分（月により28〜31）。値が0の日はハイフンではなく `¥0` 表示（未記帳と入力済みゼロ円を区別したい場合は別途「未記帳」バッジの追加を検討 — 今回のスコープ外、必要なら別途相談）。
  - 差引列: プラスは緑文字、マイナスは赤文字。
  - 月合計行: テーブル最下部に固定（sticky bottom）、濃色背景（`#1a1815` 相当）に白文字、太字。全列の月間合計。

## インタラクション & 状態
- 月選択プルダウンを変えると、その月の日別行と合計行が再計算されて表示される（既存ダッシュボードの月次/年次スイッチと同じ挙動パターンを踏襲）。
- 「CSV / PDF 出力」は現在表示中の月・店舗のテーブルをそのまま出力する（既存の「税理士向けPDF出力」と同じ導線に揃える）。
- 編集操作は一切なし（読み取り専用画面）。行タップ等で編集モーダルを開かない。
