# ハンドオフ: 現場スマホ画面をモックアップ「Lane A」に合わせて実装

## 対象
`Costra 全体モックアップ.dc.html` の `phone-row`(Lane A、5画面):
1. ホーム
2. 撮影 → 納品書 読取結果(編集＋照合)
3. 売上を撮影(AIレジ締め・編集＋照合)
4. 小口現金(残高照合)
5. 経費 手入力

いずれもモバイル実機(375px前後)向け。既存の `BottomNav.tsx` / `AppShell.tsx` の下に乗る形。

## 各画面の仕様

### 1. ホーム
- 上部: 店舗名+アイコン、通知ベル(バッジ数)。
- 「今月のざっくり」カード: 純額(緑の大きい数字)、売上/支出の内訳テキスト、比率バー(横棒2色)。
- 「要確認 N件」の琥珀バナー(タップで該当箇所に遷移)。プロジェクト方針の要確認フラグ(#b06a12 / #fbe7cf)を使用。
- 「記録する」セクション: 「納品書・レシートを撮影」(大きいオレンジのプライマリボタン、アイコン+サブテキスト)、「売上を撮影」「小口現金」「経費を手入力」の3枚(白カード)。データは既存API(ダッシュボード集計・要確認件数)に接続。

### 2. 撮影 → 読取結果(納品書)
- 上部に「要確認 N件」「合計照合(差額)」の2枚の琥珀カード。
- 明細リスト: 各行タップでインライン編集(品目名・金額)。不明瞭な行は琥珀ハイライトで「読取不明」等のラベル。行削除可能。
- 合計照合ブロック: レシート記載金額(OCR値) vs 明細合計を自動突合。一致すれば緑「✓ 一致」、不一致なら琥珀「差額 ±¥X」。
- **これはプロジェクト方針の必須仕様**(編集＋合計照合)— 既存の実装があれば configuration/色のみ確認、無ければ新規実装。

### 3. 売上を撮影(AIレジ締め)
- 撮影プレビュー(暗いグラデーション、「AI読取」バッジ)。
- 内訳リスト(現金/キャッシュレス/客数など、色ドット付き、タップで編集)、下部に売上合計(太字)。
- 合計照合結果バッジ(✓一致 は緑 #1f8a5b/#e4efe9、不一致は琥珀)。
- 「この内容で保存」プライマリボタン(オレンジ)。

### 4. 小口現金
- 「帳簿上の残高」カード(黒背景、白文字、大きい金額)。
- 「実際の残高を記入」入力欄(テンキーで数字入力、下線+カーソル表現)。
- 差額表示(琥珀バナー、±¥X)。原因メモを残せるとよい。
- テンキー(1〜6行の例、実装は数字1〜9+0+削除)。

### 5. 経費 手入力
- 金額の大きい表示(タップでテンキー入力)。
- 科目(プルダウン/選択シート)・支払方法・メモの3行リスト。
- テンキー(1〜9等)、保存ボタン。

## 共通ルール(プロジェクト方針)
- 読み取り系画面(2,3)は必ず: その場編集、要確認フラグ、合計照合バッジ、編集時の再計算。
- 色: 背景#faf7f1、本文#1a1815、ミュート#8a8378、アクセント(オレンジ)#c84a1f/ソフト#f7e6dc、緑#1f8a5b/ソフト#e4efe9、琥珀#b06a12/背景#fbe7cf。既存Tailwind(amber系)トークンに対応させ、hex直書きは避ける。
- 白カード: border #e6dfd1、角丸16〜18px。
- フォント: Noto Sans JP。モバイル幅 max 440px。

## 進め方
`claude_code_prompt.md` をClaude Codeに投入。詳細は `指示書.md`。既存のAPI(伝票登録・OCR取込 `/api/menu-items/import` 相当の仕組み、`/api/transactions` 等)に接続し、新規APIが必要なら指示書内で明示。
