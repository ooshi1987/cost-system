# 指示書(Claude Code 向け) — 日次集計表(1c)を実装

対象リポジトリ: 「cost system」(Next.js App Router + TypeScript + Prisma/PostgreSQL + Tailwind、amberアクセント、全データ`storeId`スコープ)

## 背景
サイドバーの「日次集計表」ナビ項目は既にある想定だが、ページ本体が `Costra 全体モックアップ.dc.html` の `#1c` の見た目・列構成と一致しているか確認し、一致していなければ実装/修正する。まず現状のリポジトリ(該当ページがあるか、`src/app/*` 配下を確認)を調べてから着手。

## 仕様

### レイアウト
- 既存のサイドバー(`Sidebar.tsx`)をそのまま使用。「日次集計表」項目をアクティブ表示(現状のアクティブ表現パターンに合わせる)。
- ページヘッダー: 見出し「日次集計表」+ サブテキスト「{店舗名} ・ 今のExcel(損益計算書)と同じ列構成 ・ 表示専用」。右に月セレクタ、「CSV / PDF 出力」ボタン(プライマリ、amber)。
- 注記テキスト(ミュート色、小さいフォント): 「修正はこの画面ではできません。読み間違いや仕分けの修正は、現場の記録画面(撮影・入力)側で行ってください。」

### テーブル
横スクロール対応、2段ヘッダーを`sticky`固定:
- 1段目(グループ見出し): 「売上」列群(緑系統: 背景/文字を既存の収益トークンに)、「仕入先別支出」列群(オレンジ系統: 既存のアクセントトークンに)。
- 2段目(列見出し): 日 / 曜 / 現金 / クレジット / オンライン / 売上合計 / (仕入先を動的列化、上位N社+「その他」) / 消耗品 / 水道光熱費 / その他 / 支出合計 / 差引。
- 行: 1日1行。データ無しセルは「—」。差引が正なら緑文字+「+」、負なら赤系「−」。1行おきに薄い縞背景。
- 最終行: 「◯月度合計」を濃色背景の合計行、`sticky bottom`で固定。

### データ集計ロジック
- `Transaction`(既存モデル、storeIdスコープ)を対象月・日付でグルーピング。
- 売上: 支払方法(現金/クレジット/オンライン)別に集計、`Transaction.kind = income` 側。
- 支出: 取引先(仕入先)別に集計。取引件数上位の仕入先を個別列化し、残りは「その他」列にまとめる(閾値・上位数は既存カテゴリ実装があれば合わせる、なければ上位3社+その他)。消耗品・水道光熱費・その他は既存の科目マスタ `src/lib/categories.ts` の分類に対応させる。
- 集計ロジックは `src/lib/calculations.ts` に追加するか、新規 `src/lib/dailyLedger.ts` を作り既存の計算関数群のパターンに合わせる。

### CSV / PDF出力
- 表示中の集計をそのままCSV化するAPI(または既存の `/api/reports` を拡張)を用意。PDFは既存の税理士向けPDF出力があれば同じ仕組みを流用。

### 権限・スコープ
- 全データ操作は既存の `storeId` スコープ・`auth.ts` の認可パターンを踏襲。この画面はadmin/管理者ロールのみアクセス可能とする(既存の権限モデルに従う)。

## 完了条件
- モックアップと同じ列構成・グループ色分け・合計行が表示される。
- 月切替で再集計される。
- CSV/PDF出力が動作する。
- 型チェック・lintエラーなし。
