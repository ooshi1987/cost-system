# Claude Code 投入文（日次集計表 — 今のExcelと同じ見え方のビュー）

> このリポジトリ「cost system」に、**管理者PC向けの「日次集計表」画面**を追加してください。詳細仕様は `design_handoff/指示書.md` にあります。まずそれと `design_handoff/README.md`、既存の売上・支出データを持つモデル（想定 `Transaction`／`storeId`スコープ）、既存ダッシュボード実装（`src/app/dashboard/*`）、既存サイドバー/ナビの実装コンポーネントを読んでから着手してください。想定しているモデル名・フィールド名が実際と違う場合は、実コードに合わせて読み替えてください。

## 前提
現場は今後スマホで撮影・入力して記帳する運用に移行するが、運営が使い慣れている今のExcel（損益計算書シート：1日1行、左に売上の支払方法別内訳、右に仕入先ごとの支出額）と同じ見え方の集計画面を、管理者PCのダッシュボードに追加する。**表示専用**（このリポジトリの入力系画面の必須仕様＝その場編集・要確認フラグ・合計照合は、この画面には適用しない。数値の修正は元の記帳画面側で行う）。

## スコープ
1. **`/daily-ledger`**（`page.tsx` server ＋ `DailyLedgerClient.tsx` client）を新設。サイドバーに新規ナビ項目「日次集計表」を追加（既存「ダッシュボード」の直下）。
2. 新規集計ロジック `src/lib/dailyLedger.ts`: 対象店舗・対象月の取引を日付でグルーピングし、
   - 売上: 入金チャネル（`method`）ごとに日別合計＋日別売上合計。
   - 支出: 取引先（`vendor`、無ければ科目名）ごとに日別合計。**列は固定せず、当月支出額の上位5〜6件＋「その他」で動的に構成**（Excelは取引先ごとに列があるが、本番は取引先数が多いため動的上位N＋その他で再現）。
   - 差引 = 売上合計 − 支出合計（日別・月合計とも）。
   - 月合計行（全列）も算出。
3. 表: グループヘッダー「売上」（緑）／「仕入先別支出」（amber）＋列ヘッダー＋日別行＋月合計行（sticky, 濃色強調）。横スクロール対応。差引はプラス=緑／マイナス=赤。月選択プルダウンで対象月を切替。
4. 出力: 既存にCSV/PDF出力の仕組みがあれば流用して追加。無ければCSV出力のみ実装し、PDFは既存「税理士向けPDF出力」があればそこに乗せる形で拡張（無ければ今回は実装せず提案に留める）。

## 制約
- **この画面に編集UIは一切追加しない**（表示専用）。
- スタイルは既存 Tailwind / 既存CSS変数（amber系）。プロトタイプのhex直書き禁止。
- すべて `storeId` スコープ＋既存認可方式。既存の画面・API・ナビは**無変更で動作**（非破壊）。
- 集計はDB側 `groupBy` を使い、N+1を避ける。
- `tsc --noEmit` / `eslint` をクリーンに保つ。エラーは日本語・既存トーン。

## 完成の確認
サイドバーから「日次集計表」に遷移でき、月選択で対象月の日別行（売上=チャネル別内訳＋合計、支出=上位取引先＋その他＋合計、差引）と月合計行が表示される／編集手段が存在しない／既存機能に影響がない。
